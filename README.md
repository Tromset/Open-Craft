# Minecraft (navigateur)

Clone voxel jouable en TypeScript + Three.js.

## Lancer

```bash
npm install
npm run dev
```

Ouvre l’URL affichée (souvent `http://localhost:5173`), clique pour capturer la souris.

## Contrôles

| Action | Touche |
|--------|--------|
| Avancer / reculer / straf | ZQSD ou WASD |
| Regarder | Souris |
| Sauter / nager | Espace |
| Sprint | Shift |
| Casser | Clic gauche |
| Poser | Clic droit |
| Choisir un bloc | 1–9 ou molette |
